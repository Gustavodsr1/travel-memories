# Travel Memories

Site estático com álbum de viagens e trilha sonora ambiente em reprodução contínua com recuperação automática de playback.

## Publicação no GitHub Pages

1. Crie o repositório `travel-memories` em `https://github.com/new`.
2. Na raiz deste projeto, execute:

```bash
git push -u origin main
```

3. No GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Depois do push, o workflow `.github/workflows/deploy-pages.yml` publica o site automaticamente.
